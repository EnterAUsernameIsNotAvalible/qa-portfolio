# SQL

Практика SQL: SELECT, JOIN (INNER/LEFT), агрегація (GROUP BY/HAVING), підзапити (IN/EXISTS).

**[sql_practice.md](./sql_practice.md)** — журнал розв'язаних задач. Кожен запит має:
- **Задача** — умова своїми словами
- **Пастка** — конкретна помилка, яку зробив і виправив
- **SQL** — фінальний робочий запит

Формат навмисно показує не тільки правильні відповіді, а й типові помилки (плутанина `таблиця.поле` в ON, `WHERE` vs `HAVING`, `COUNT(*)` vs `COUNT(column)`) — це те, що зазвичай перевіряють на технічній співбесіді для QA.

**Стек:** SQLite (SQLBolt, sql-academy.dev).
